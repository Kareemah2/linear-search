About Linear Search

Linear search scans each record one by one from the first element until a match is found or the list ends. It is simple and effective when data is unsorted.

Advantages

  • Very easy to implement
  • No sorting required
  • Works for small datasets

Disadvantages

  • Slow for large datasets
  • Checks may be many
  • Not optimized for repeated queries

Use Cases

  • Unsorted lists
  • Occasional lookups
  • Educational visualization

How Linear Search Works

  1. 1Start from the first student record.
  2. 2Compare target query with current student's name and matric number.
  3. 3If no match, continue to the next record.
  4. 4Stop immediately when match is found.
  5. 5Return “Not Found” if the end is reached.
